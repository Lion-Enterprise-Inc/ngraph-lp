FDE-style support
Enter the workplace→Organize the record→Put AI on site→Start with one task→Keep it as a pattern
  1. STEP 01 Enter the workplace

    See the work, the decisions, the exceptions, and the data in use

  2. STEP 02 Organize the record

    ABC sorting × Status sorting brings scattered information into the Company Brain

  3. STEP 03 Put AI on site

    Install Claude Code / Codex on work PCs and connect them to the record

  4. STEP 04 Start with one task

    Build the first use case, then refine it in use until it sticks

Decisions, procedures, lessons: back into the record, then on to the next task

The result isn't a delivered AI. It's a system used on site that stays with the company.
