「ハードが本体、ソフトはおまけ」の1975年に、19歳と22歳が『PCには OS とソフトウェアが要る』に全張りした

当時の状況

1975年4月、ハーバード休学の Bill Gates（19歳）と Honeywell を辞めた Paul Allen（22歳）が、ニューメキシコ州アルバカーキの MITS 本社近くで Micro-Soft を創業。同年1月号の Popular Electronics 誌で Altair 8800 を見た瞬間、Allen が雑誌を持って Gates の寮に駆け込んだのが発端。実機を持たないまま PDP-10 上で 8080 をエミュレートし8週間で BASIC インタプリタを書き上げ、Allen が Albuquerque 行きの飛行機の中で初めてブートローダを書き、MITS 社長 Ed Roberts の前で初回実行に成功してロイヤリティ契約を締結。前身の Traf-O-Data（交通量解析）は失敗済み。二人は安ホテルに住み込み、社員数名、売上は MITS からのロイヤリティのみ。

12項目の採点（33/60）

ターゲット市場3/51975年のマイコン市場は世界で年間数千台、$10M未満。ホビイスト中心で『市場』未成立。ただし PC が普及すれば $10B+ 級に化ける潜在規模
課題の実在性4/5Altair 8800 は LED とトグルスイッチのみ。プログラムを書く手段がない、というハードユーザーの実痛。MITS Roberts も BASIC を欲しがっていた
ソリューション5/5Altair BASIC は 4KB に収まり、実機なしで PDP-10 上の 8080 シミュレータで開発、初回実行で動いた。当時の他のマイコン用言語処理系より明らかに10倍以上の体験差
チーム4/5Gates（コンパイラ・営業）+ Allen（システム・ハード理解）の補完。Lakeside School から PDP-10 で実コードを書いてきた異常な早熟ペア。ただし経営経験ゼロ、Traf-O-Data で失敗済み
トラクション2/5有料顧客は MITS 1社のみ。ロイヤリティ契約だが Altair ユーザーは雑誌で配布される海賊版 BASIC を使い、Gates が1976年『An Open Letter to Hobbyists』で抗議する状態。実質売上は伸び悩む
参入障壁2/5ライセンス契約と8週間で書き切ったコード資産はあるが、ネットワーク効果なし、データ優位なし、コスト構造優位なし。模倣は他社にも可能。先行者優位レベル
収益モデル2/5MITS ロイヤリティ（上限 $180,000）依存。ユニットエコノミクスは成立しているが、契約相手1社・市場サイズ自体が小さい。1975年売上 $16,005
財務計画2/5Gates・Allen の自己資金と Gates 家からの支援で運転、外部調達なし。ブートストラップで延命、計画は走りながら立てる状態
資本効率3/5社員数人、設備は時間貸しの PDP-10、家賃は安ホテル。資本効率は良いがそもそも投下資本が極小で『効率』を語る規模ではない
出口戦略2/5出口設計なし、創業者継続前提。1986年 IPO は11年先。資本独立志向は明確だが手段は未確定
タイミング5/5Intel 8080（1974年）+ Altair 8800（1975年1月号 Popular Electronics）+ 半導体価格の急落、PC 革命の点火点ちょうど。Gates が言う『誰も気付いていない6ヶ月の窓』に滑り込んだ
独自の洞察5/5『ハードが本体、ソフトはおまけ』が業界常識だった1975年に『PC には必ず OS とソフトウェアが要る、それが本体になる』と賭けた。Apple も Commodore も当時はハード会社。25年後に Windows + Office で証明、業界全体が後追いした（3条件 Yes）

テレスの所感

1975年のマイクロソフトは、19歳と22歳がアルバカーキの安ホテルから業界全員と逆張りした賭けだ。Altair 8800 を雑誌の表紙で見て、実機を一度も触らないまま PDP-10 上で 8080 をエミュレートし、8週間で BASIC を書き上げ、Allen は飛行機の中でブートローダを書いて、初回実行で動かした——この一発勝負を勝てなければ Traf-O-Data に続く2度目の失敗で終わっていた。賭けの本質は『ハードが本体』が常識だった時代に『ソフトこそ本体になる』を見抜いたこと。Gates が後に語る『誰も気付いていない6ヶ月の窓』を、業界で唯一こじ開けた瞬間がここにある。L=5 はこの一点で正当化される。E・F・G が低くてもタイミングと洞察で生き残れる、NCG 特例（Timing 5 + Insight 5）の教科書例。

存続の鍵

MITS との Altair BASIC ロイヤリティ契約を初回実行成功で勝ち取ったこと、そして Gates が業界全員と逆に『ソフトが本体になる』と1975年時点で賭けたことの2点が無ければ、Traf-O-Data に続く2度目の失敗で消えていた。E・F・G が弱くても Timing 5 + Insight 5 で生存できる NCG 特例の原型。
